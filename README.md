## 💬 Chatify — WhatsApp Link Opener (Malaysia)

**Chatify** is a lightweight Flutter app that lets you open any Malaysian phone number directly in **WhatsApp** — without saving it to your contacts.
Just type the number in **any format**, tap the button, and start chatting instantly 🚀

---

### 🪄 Features

* Accepts **any Malaysian number format**, such as:

  ```
  0123456789
  60123456789
  +6012-345 6789
  012-345 6789
  012 345 6789
  ```
* Automatically cleans and converts the number into WhatsApp’s official format:

  ```
  https://wa.me/60123456789
  ```
* Instantly opens WhatsApp chat 📱
* Designed specifically for **Malaysian users**

---

### 🧠 How It Works

Chatify automatically:

1. Removes all spaces, dashes, and symbols
2. Converts the number into the proper Malaysian format (`6012xxxxxxx`)
3. Opens the link `https://wa.me/<number>` in WhatsApp
